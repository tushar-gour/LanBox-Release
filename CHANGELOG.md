# Changelog

[Back to README](README.md)

This changelog covers verified public product releases. It focuses on behavior visible to LanBox users.

## v0.3.0

- Expanded typed SDK contracts and runtime response validation
- Added typed readiness, runtime information, and runtime statistics APIs
- Added message inspection and deletion
- Added raw message and attachment downloads
- Added opaque cursor pagination
- Improved session and checkpoint workflows
- Improved network retry and cancellation behavior
- Improved search, pagination, SMTP, persistence, and storage reliability
- Expanded production, migration, chaos, and scalability validation

See the [v0.3.0 release notes](https://github.com/tushar-gour/LanBox-Release/releases/tag/v0.3.0).

## v0.2.0

- Added the official TypeScript client and CLI
- Added isolated testing sessions and session-specific addresses
- Added magic-link extraction and filtering
- Added typed errors, assertion helpers, and automation-focused examples

See the [v0.2.0 release notes](https://github.com/tushar-gour/LanBox-Release/releases/tag/v0.2.0).

## v0.1.0

- First public LanBox release
- Added local SMTP capture and virtual `@lanbox.test` inboxes
- Added the browser inbox, OTP extraction, email waiting, raw message inspection, and attachment downloads
- Added PostgreSQL persistence and container-based operation

See the [v0.1.0 release notes](https://github.com/tushar-gour/LanBox-Release/releases/tag/v0.1.0).

The existence of a package version alone is not treated as a separate documented product release.
