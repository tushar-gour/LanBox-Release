# Support

[Back to README](README.md)

## Before opening an issue

1. Read [Getting started](docs/GETTING_STARTED.md).
2. Check [Troubleshooting](docs/TROUBLESHOOTING.md).
3. Review the [FAQ](docs/FAQ.md).
4. Confirm the behavior against the current stable release, `v0.3.0`.

## Public issues

[GitHub Issues](https://github.com/tushar-gour/LanBox-Release/issues) may be used for:

- reproducible product bugs
- documentation problems
- feature requests
- usage questions that are safe to discuss publicly

Include the LanBox version, deployment method, operating system, Node.js version when using npm tooling, PostgreSQL version, and a minimal reproduction. Remove message bodies, OTP values, credentials, tokens, personal information, and private URLs before posting.

This repository does not accept LanBox implementation source or private development material.

## Security reports

Do not report vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md).
