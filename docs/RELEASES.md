# Release history

[Back to README](../README.md) | [Changelog](../CHANGELOG.md)

This repository uses tags as public documentation and release markers. They do not represent publication of LanBox implementation source.

## v0.3.0

LanBox v0.3.0 expands its public testing capabilities and improves reliability across common development and automated-testing workflows.

Highlights include typed readiness and runtime APIs, message inspection and deletion, raw message and attachment downloads, opaque cursor pagination, improved sessions and checkpoints, stricter response validation, and broader production testing.

Distribution:

- [@lanbox/client@0.3.0](https://www.npmjs.com/package/@lanbox/client/v/0.3.0)
- [@lanbox/cli@0.3.0](https://www.npmjs.com/package/@lanbox/cli/v/0.3.0)
- [ghcr.io/tushar-gour/lanbox:0.3.0](https://github.com/users/tushar-gour/packages/container/package/lanbox)
- [GitHub Release](https://github.com/tushar-gour/LanBox-Release/releases/tag/v0.3.0)

## v0.2.0

LanBox v0.2.0 introduced the official TypeScript client, CLI, isolated testing sessions, session addresses, magic-link extraction and filtering, typed errors, assertion helpers, and improved automation examples.

- [GitHub Release](https://github.com/tushar-gour/LanBox-Release/releases/tag/v0.2.0)

## v0.1.0

The first public LanBox release provided local SMTP capture, virtual `@lanbox.test` inboxes, a browser inbox, OTP extraction, email waiting, raw message inspection, attachment downloads, PostgreSQL-backed persistence, and container usage.

- [GitHub Release](https://github.com/tushar-gour/LanBox-Release/releases/tag/v0.1.0)

No separate v0.2.1 GitHub product release is documented because package-version evidence alone is not sufficient to establish a distinct verified product release.
